Ketentuan Layanan

Terakhir diperbarui: 17 Oktober 2026

Dimas Affiliate Studio adalah asisten Telegram pribadi untuk membantu pemilik akun meninjau data TikTok yang diizinkan melalui API resmi dan merencanakan konten affiliate. Layanan ini saat ini disiapkan untuk penggunaan pemiliknya, bukan ditawarkan sebagai layanan publik.

Akses dan penggunaan

Penggunaan fitur TikTok memerlukan otorisasi pemilik akun dan scope API yang disetujui TikTok. Asisten hanya dapat menampilkan data yang tersedia pada endpoint dan izin tersebut. Akses dapat berubah atau dihentikan jika token dicabut, izin tidak tersedia, atau TikTok mengubah layanan API-nya.

Pengguna bertanggung jawab menjaga kredensial, menggunakan bot hanya dari akun Telegram yang diizinkan, memeriksa hasil sebelum digunakan, dan mematuhi ketentuan TikTok, TikTok Shop, serta layanan pihak ketiga yang dipakai.

Hasil dan konten affiliate

Analisis, ide produk, naskah, prompt, dan rekomendasi dibuat sebagai bantuan. Data API dapat terbatas atau terlambat; hasil tidak menjamin performa, penjualan, komisi, atau pendapatan tertentu. Pengguna harus memverifikasi harga, stok, klaim produk, tautan affiliate, dan pengungkapan konten sebelum menerbitkan materi.

Ketersediaan dan perubahan

Fitur dapat berubah seiring ketersediaan API dan layanan yang digunakan. Asisten tidak boleh digunakan untuk mengakses akun atau data tanpa izin, menghindari batas API, atau mengirim konten tanpa persetujuan yang diwajibkan platform.

Kontak

Layanan ini saat ini hanya untuk penggunaan pribadi pemiliknya. Untuk pertanyaan umum tentang halaman ini, gunakan Issues pada repositori GitHub. Jangan kirimkan data pribadi atau kredensial melalui issue publik.
